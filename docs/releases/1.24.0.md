# Diary 1.24.0 release closeout

Diary [1.24.0](https://github.com/POBSIZ/obsidian-diary/releases/tag/1.24.0) improves wording across eight UI languages and fixes text clipping on narrow screens. This record describes the release and checks observed on **2026-10-18**. Times use Asia/Seoul (UTC+09:00).

## Shipped changes

The copy review covered English, German, Spanish, French, Japanese, Simplified Chinese, Traditional Chinese and Korean. It changed **584 existing message values** and added **14 custom-calendar validation messages per locale**. Existing message keys and placeholders were preserved. Validation now returns message keys that the settings UI translates.

Labels describe the available action or setting with less jargon. Examples include **Secondary calendar** and **New note format**, with Korean **보조 달력** and **새 노트의 기본 형식**. Read-only guidance remains explicit, and date-format ambiguity guidance includes conflicting token structures even when they currently yield the same date.

Calendar badges, status labels and feedback controls wrap within their containers. Mobile calendar settings avoid nested horizontal padding that clipped long selected values. Monthly planner and list headings use the existing locale messages for month–year order, including Korean **2026년 11월**. The root README and eight localized READMEs describe the release; `design.md` records the wrapping and date-label rules.

## Runtime verification

Checks used **Obsidian 1.14.4**, initially running Diary **1.23.1** with the revised build. All eight locales were checked in a **640 × 800 desktop Settings window** and **390 × 844 Chromium/Electron mobile emulation**. Covered surfaces included settings, custom-calendar validation with a blank name and disabled Save, external-feed creation, range/repeat file-creation controls and the monthly view switcher. DOM measurements checked overflow and selected-value widths; native screenshots were inspected for representative Korean, German and English screens. The affected checks passed after wrapping and padding fixes.

Forms were canceled without saving; no notes were created or modified. The temporary monthly tab was removed, Korean and desktop mode were restored, and the desktop viewport returned to **1720 × 1410**. No physical iOS/Android testing or native-speaker review was performed.

After installing the downloaded release assets and reloading, the running plugin reported **1.24.0**. Korean settings displayed the revised labels, and the loaded monthly view displayed **2026년 10월**. Developer error and console checks reported no errors at that verification.
