# Diary 1.26.1

Diary 1.26.1 reduces repeated work in planner rendering, reminders, recurring events and settings saves. This patch retains the existing commands, settings keys, date filenames and recurring-event identities.

## Changes

- Use bounded holiday/date formatter caches and indexed date-range lookups for notes and external events. The 3-day planner expands overlays once for its visible period.
- Update reminder metadata for changed files instead of enumerating the vault after every change. Folder, scan-scope and date-format changes still rebuild the index; pending work is cancelled on unload.
- Skip nonmatching daily/weekly recurrence dates and share calendar conversions within each expansion. Calendar rules, exclusions, materialized occurrences, colors and ordering retain their existing behavior.
- Validate changed settings without rebuilding unchanged external-event caches. Plan-note collapse/expand updates the existing panel, and yearly month expansion refreshes the yearly views.
- Share event-detail actions across planner views and separate external-calendar settings into focused modules.

## Measurement and regression evidence

The [phase 1 report](../performance/2026-11-14.json) and [phase 2 report](../performance/2026-11-14-phase2.json) retain methods, fixtures, source hashes and raw results. These measurements describe this Mac and these datasets; they are not guarantees for every vault or device.

The live macOS Obsidian comparison used the published 1.26.0 build and the combined candidate with the same visible dates and viewport. After a warm-up render and 250 ms settle, 31 synchronous render calls gave these medians:

| View | 1.26.0 | Candidate |
| --- | ---: | ---: |
| Monthly grid | 9.0 ms | 4.1 ms |
| Monthly sidebar | 8.1 ms | 4.0 ms |
| 3-day | 14.5 ms | 2.6 ms |

Per-date content hashes, element counts and chip counts matched. This measures render function time, excluding end-to-end paint and startup. The candidate was tested before the release version marker changed.

Offline differential checks matched complete recurring-event outputs in 600 calendar/range/time-zone cases, plus reminder notices, ordering and duplicate-delivery keys. Settings comparisons covered persisted values and callbacks, 64 external-calendar settings states across eight locales, and add/edit validation. Existing date-format, note creation/movement, color, external-calendar and sidebar regressions remain in the test suite.

Physical iOS and Android devices were not tested. UI strings and CSS rules are unchanged; the stylesheet release marker changes to 1.26.1. The bundle is slightly larger, and startup latency was not measured. The pre-existing 10,000-step limit for old ICS daily recurrences is outside this patch.
